BACKGROUND LOCATION
The "location" background mode (UIBackgroundModes) is used by ONE feature only: Home screen ("Сеть" tab) -> "Record route" (Russian UI: «Записать маршрут»).
While the user records a route, the app saves every few seconds the device position and the network quality there (TCP connect time to 1.1.1.1, connection type, optionally a short download-speed sample). The map shows the route coloured by quality and marks places without connectivity. This needs continuous location while the phone is in a pocket, a car or a train.

USER CONTROL
- Recording starts ONLY when the user taps "Record route"; never at launch. The only way a recording continues without the app open is the opt-in switch below.
- While recording, the iOS location indicator and a red "Recording" pill with a timer are visible; the user ends it with "Stop and save".
- Location permission ("While Using the App") is requested only after that tap; the purpose string says the data stays on the device.
- Routes are stored on the device, excluded from backups, never uploaded; the user can delete one route or all routes.
- "Настройки" tab -> "Запись маршрута": "Записывать маршрут в фоне" (default on; when off, no location in the background) and auto-stop after 20 minutes without movement.
- There too: "Продолжать запись после закрытия приложения" (keep recording after the app is closed), OFF by default. Only if the user turns it on, the app asks for "Always" location and, only WHILE a route is recorded, uses significant-location-change monitoring: if the app was swiped away, iOS may relaunch it after about 500 m of movement and the recording continues in the same route. It stops when recording stops or the user opens the app. Nothing else happens on that launch.
- There too: «Режим «Поездка»» (on by default): while recording, warns about weak connectivity ahead using ONLY the user's own saved routes. Nothing new is collected.
- All other features (speed test, tools, widget, Dynamic Island) work without location permission.

The map (Apple MapKit) is the home screen, visible before any permission. The route colour comes from the app's own ping, not from location data; no operator coverage data is used.

HOW TO TEST
1. Drag the bottom panel up -> "Показать пример маршрута": a labelled DEMO route is drawn.
2. Tap "Записать маршрут" -> allow "While Using the App" (Simulator: Features -> Location -> City Run), then "Остановить и сохранить": the route is saved under "Мои маршруты" and can be deleted there.

STABILITY TEST ("Инструменты" tab -> «Тест стабильности», free)
The user starts a 5-60 minute test: once a second the app opens a TCP connection to public DNS servers (about 5 MB per hour) and shows losses, latency and outages. On iOS 26 it runs as a user-initiated BGContinuedProcessingTask (system progress UI, the user can cancel); on earlier iOS only while the app is open. No location, no account.

ADVERTISING AND TRACKING
No advertising, no third-party SDKs, no analytics, no tracking (no AppTrackingTransparency). App Privacy: "Data Not Collected". No account, no server. The AI audit runs on the device.
