BACKGROUND LOCATION
The "location" background mode (UIBackgroundModes) is used by ONE feature only: Home screen ("Сеть" tab) -> "Record route" (Russian UI: «Записать маршрут»).
While the user records a route, the app saves every few seconds the device position and the network quality there (TCP connect time to 1.1.1.1, connection type, optionally a short download-speed sample). The map shows the route coloured by quality and marks places without connectivity. This needs continuous location while the phone is in a pocket, a car or a train.

USER CONTROL
- Recording starts ONLY when the user taps "Record route"; never at launch. The only way a recording continues without the app open is the opt-in switch described below.
- While recording, the iOS location indicator is visible, the map screen shows a red "Recording" pill with a timer, and the user ends it with "Stop and save".
- Location permission ("While Using the App") is requested only after that tap; the purpose string says the data stays on the device.
- Routes are stored on the device, excluded from backups, never uploaded; the user can delete one route or all routes.
- "Настройки" tab -> "Запись маршрута": the switch "Записывать маршрут в фоне" (default on); when off, the app does not use location in the background. A second switch stops a recording after 20 minutes without movement.
- Same section: "Продолжать запись после закрытия приложения" (keep recording after the app is closed), OFF by default. Only if the user turns it on, the app asks for "Always" location (own purpose string) and, only WHILE a route is recorded, uses significant-location-change monitoring: if the app was swiped away, iOS may relaunch it after about 500 m of movement and the recording continues in the same route. Monitoring stops when recording stops or the user opens the app. Nothing else happens on that launch.
- "Экономия заряда" (battery saver, off by default): one switch that makes the app work less often. It adds no data collection.
- All other features (speed test, tools, widget, Dynamic Island) work without location permission.

The map (Apple MapKit) is the home screen, visible before any permission is requested. The route colour comes from the app's own ping, not from location data; no operator coverage data is used.

HOW TO TEST
1. Drag the bottom panel up -> "Показать пример маршрута" (Show example route): a labelled DEMO route is drawn.
2. Tap "Записать маршрут" (Record route) -> allow "While Using the App". In the Simulator use Features -> Location -> City Run.
3. Tap "Остановить и сохранить" (Stop and save): the route is saved under "Мои маршруты" (My routes), where it can be deleted.
