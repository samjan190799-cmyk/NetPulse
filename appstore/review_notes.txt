BACKGROUND LOCATION
The "location" background mode (UIBackgroundModes) is used by ONE feature only: Home screen ("Сеть" tab) -> "Record route" (Russian UI: «Записать маршрут»).
While the user records a route, the app saves every few seconds the device position and the network quality at that place (TCP connect time to 1.1.1.1, connection type Wi-Fi / 5G / 4G / 3G / 2G, optionally a short download-speed sample). The map then shows the route coloured by quality (good / fair / poor / no connection) and marks places without connectivity. This needs continuous location while the phone is in a pocket, a car or a train.

USER CONTROL
- Recording starts ONLY when the user taps "Record route"; never at launch or after a restart.
- While recording, the iOS location indicator is visible, the map screen shows a red "Recording" pill with a timer, and the user ends it with "Stop and save".
- Location permission ("While Using the App") is requested only after that tap; the purpose string says the data stays on the device.
- Routes are stored on the device, excluded from backups, never uploaded; the user can delete one route or all routes.
- "Настройки" tab -> "Запись маршрута": the switch "Записывать маршрут в фоне" (default on). When it is off, the app does not use location in the background. A second switch stops a recording automatically after 20 minutes without movement.
- All other features (speed test, tools, widget, Dynamic Island) work without location permission.

The map (Apple MapKit) is the home screen, visible before any permission is requested. The route colour comes from the app's own ping, not from location data; no operator coverage data is used.

HOW TO TEST
1. The first screen is the map with the bottom panel (network speed and two buttons).
2. Drag the panel up -> "Показать пример маршрута" (Show example route): a labelled DEMO route is drawn on the map.
3. Tap "Записать маршрут" (Record route) -> allow "While Using the App". In the Simulator use Features -> Location -> City Run.
4. Tap "Остановить и сохранить" (Stop and save): the route is saved under "Мои маршруты" (My routes), where it can be deleted.

ADVERTISING AND TRACKING
The app contains no advertising, no third-party SDKs and no analytics, and does not track users: it does not use the AppTrackingTransparency framework and does not request the App Tracking Transparency permission. App Privacy answers: "Data Not Collected". No account, no server. The AI audit runs entirely on the device (no external AI services). The app has no microphone or speech-recognition features.
