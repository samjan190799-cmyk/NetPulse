# ⚡ NetPulse — Real-Time Network Quality Monitor

**NetPulse** — это легковесный, высокопроизводительный инструмент для непрерывного мониторинга качества сетевого соединения в реальном времени, глубокой сетевой диагностики и анализа стабильности каналов связи.

---

## 🌟 Ключевые возможности

1. **Многопротокольный параллельный Ping Engine (ICMP & TCP)**:
   - Непрерывный асинхронный опрос заданных узлов (Cloudflare DNS, Google DNS, Yandex DNS, Quad9, локальный шлюз).
   - Поддержка нескольких режимов: `auto` (умный автовыбор с резервированием), `tcp` (не требует прав root/Admin), `icmp` (сырые сокеты) и `subprocess` (системный ping).

2. **Математический анализ качества соединения (RFC 3550 Jitter & Latency)**:
   - Расчет межпакетного джиттера в строгом соответствии со стандартом **RFC 3550** ($J_i = J_{i-1} + \frac{|D| - J_{i-1}}{16}$).
   - Перцентили задержки (**P50 / Median**, **P95**, **P99**), минимальный, средний и максимальный RTT.
   - Процент потерь пакетов (**Packet Loss %**) в скользящем окне и за всю сессию.

3. **Сетевая диагностика и авто-MTR / Traceroute**:
   - Автоматическое определение локального IP, основного шлюза (Default Gateway), DNS-серверов.
   - Определение публичного IP, страны, города и интернет-провайдера (ISP / AS).
   - **Auto-MTR**: При превышении порогов потерь пакетов (> 5%) или скачке задержки (> 150 мс) автоматически запускается трассировка маршрута.

4. **Замер пропускной способности (Bandwidth & Speedtest)**:
   - Встроенный асинхронный замер скорости скачивания (**Download Mbps**) и отдачи (**Upload Mbps**) через CDN-эндпоинты Cloudflare по горячей клавише `[S]`.

5. **Премиальный интерфейс (Dual Mode)**:
   - **Rich Interactive TUI**: Интерактивный терминальный дашборд с Unicode/Braille sparkline-графиками, цветовой индикацией статусов, журналом аномалий и панелью управления.
   - **Web Dashboard**: Современный Glassmorphism веб-интерфейс с графиками **Chart.js** в реальном времени, доступный по флагу `--web`.

6. **Долговременное хранение и экспорт**:
   - Автоматическое логирование всех измерений в базу данных **SQLite** (`netpulse_history.db`).
   - Экспорт детальных отчетов сессии в форматы **JSON** и **CSV**.

## 🚀 Установка и запуск

### Требования
* **Python 3.11+** (или Python 3.10+)
* Операционная система: Windows, Linux или macOS.

### 1. Установка зависимостей (опционально)
```bash
pip install -r requirements.txt
```

> **Примечание**: NetPulse спроектирован так, что основные модули и тесты могут работать даже при базовой стандартной библиотеке Python с установленной библиотекой `rich`.

### 2. Запуск TUI-монитора в терминале
```bash
python main.py
```

### 3. Запуск с веб-интерфейсом
```bash
python main.py --web --port 8080
```
После запуска откройте в браузере: `http://127.0.0.1:8080`

### 4. Мониторинг пользовательских хостов
```bash
python main.py --hosts "1.1.1.1,8.8.8.8,google.com,github.com" --interval 0.5
```

## ⌨ Горячие клавиши в терминале

| Клавиша | Действие |
|:-------:|:---------|
| `S` | Запустить тест скорости скачивания и отдачи (**Speedtest**) |
| `T` | Запустить трассировку маршрута (**Traceroute / MTR**) |
| `E` | Экспортировать отчет текущей сессии в файлы `.json` и `.csv` |
| `W` | Открыть Web-дашборд в браузере (если запущен с `--web`) |
| `Q` | Завершить работу приложения с авто-сохранением сессии |

## 🛠 Параметры командной строки (CLI)

```
usage: main.py [-h] [-H HOSTS] [-i INTERVAL] [-t TIMEOUT] [-m {auto,tcp,icmp,subprocess}] [-w] [-p PORT] [-s]

Параметры:
  -h, --help            Показать справку по аргументам
  -H, --hosts HOSTS     Список хостов через запятую (например: '1.1.1.1,8.8.8.8,google.com')
  -i, --interval N      Интервал проверки в секундах (по умолчанию 1.0)
  -t, --timeout N       Таймаут одного пинга в секундах (по умолчанию 2.0)
  -m, --mode MODE       Режим пинга: auto, tcp, icmp, subprocess (по умолчанию auto)
  -w, --web             Включить встроенный Web Dashboard
  -p, --port PORT       Порт Web Dashboard (по умолчанию 8080)
  -s, --sound           Включить звуковые оповещения при сбоях
```
